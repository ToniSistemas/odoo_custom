# Ocultar Empaquetado en Albaranes

## Descripción
Este módulo permite ocultar la columna "Empaquetado" en las líneas de albaranes (stock.picking) mediante los checkboxes de columnas opcionales.

## Características
- Agrega la columna "Empaquetado" a las columnas opcionales que se pueden ocultar/mostrar
- La columna aparece visible por defecto pero puede ocultarse mediante el checkbox

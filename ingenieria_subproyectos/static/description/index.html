Subproyectos

Jerarquía de proyectos principales y subproyectos para ingeniería

Proyectos principales

Agrupa proyectos relacionados bajo un proyecto principal. Vista Kanban clara con el número de subproyectos.

Subproyectos

Cada subproyecto tiene su propio equipo, tareas, etapas y seguimiento de horas.

Tareas y subtareas

Flujo estándar de Odoo dentro de cada subproyecto. Compatible con imputación de horas y facturación.

Flujo de trabajo

  • 📁 Proyecto principal — activa "Es proyecto principal" y crea el contrato en ventas
  • 🗂️ Subproyectos — crea uno por cada fase o disciplina (estructura, instalaciones...)
  • ✅ Tareas — cada subproyecto gestiona su propio tablero Kanban de tareas
  • 🧾 Certificaciones — el módulo ingenieria_certificaciones factura por el proyecto principal
